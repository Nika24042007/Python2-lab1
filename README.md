## Инструкция использования
### Запуск
```python -m src.main```

### Основная инструкция (алгоритм решения)
    1. Пользователь вводит команду из списка (если коменды нет в списке выводится ошибка)
    2. Если выбрано создание источника, то нужно выбрать тип источника из списка (если типа нет в списке, то будет выводится ошибка)
    3. Даллее во всех случаях попросят ввести название источника
        3.1. Команда создания источника. Источник с введенным именем не должен существовать, иначе ошибка
        3.2 Команда получения задания. Источник с введенным именем должен существовать, иначе ошибка
    4. Далее в зависимости от типа источника:
        - File:
            1. Получение одного задания. Выбрать id источника из списка и получить задание
            2. Получение всех задание. Просто будут выведены все задания с их id
            3. Примечание: если файл пуст, нет такого id, файл не формата json будет выводится ошибка
        - Api:
            1. Получение одного задания. Ввести задание и получить его обратно с id
            2. Получение всех заданий. Выбрать количество заданий, ввести из и получить обратно с id
        - Generator:
            1. Получение одного задания. Получение одног рандомного задания с id
            2. Получение всех заданий. Получение рандомного количества заданий с рандомным содержанием
    5. Ввести "exit" для завершения
